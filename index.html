Política de Privacidad y Seguridad de Datos

Sistema de Gestión de Tratamientos Químicos — Pluspetrol

Última actualización: agosto de 2026

Este documento describe cómo EDGE SA ("la Empresa", "Nosotros") recopila, procesa, almacena y protege los datos en el contexto del sistema de gestión de tratamientos químicos operado para Pluspetrol. El sistema incluye la aplicación móvil QuickCheck, el dashboard web, la plataforma IoT backend, la infraestructura cloud y los dispositivos de telemetría de campo.

Resumen: El sistema es una plataforma IoT industrial de telemetría, dosificación y mantenimiento. Los únicos datos personales almacenados son las credenciales de acceso de los usuarios autorizados (nombre, email, rol). Todos los demás datos son operativos e industriales. La infraestructura está alojada en un entorno dedicado exclusivamente a Pluspetrol, sin compartir datos con otros clientes de EDGE SA.

3. Datos que el sistema recopila

3.1 Datos de usuarios (datos personales)

El sistema almacena únicamente los datos estrictamente necesarios para autenticación y trazabilidad operativa:

  • Nombre completo y email corporativo: Pre-registrados por EDGE SA. Se utilizan para autenticación, asignación de rol y asociación de reportes con el técnico responsable.
  • Rol asignado: Determina las vistas y acciones disponibles en la app y el dashboard. Embebido en el token de sesión al momento del login.
  • Token de sesión: Almacenado de forma cifrada en el dispositivo móvil durante la sesión activa. Eliminado al cerrar sesión o desinstalar la app.

3.2 Datos de telemetría industrial (datos operativos)

Generados automáticamente por los dispositivos de campo. No contienen información personal. Incluyen: nivel de tanque por canal, presión, caudal, estado de batería, nivel de señal y estado de conexión de cada dispositivo.

3.3 Datos de reportes de mantenimiento

Generados por los técnicos a través de la app móvil:

  • Checklists de inspección de equipos (estado de válvulas, contenedores, conexiones, etiquetas, etc.).
  • Datos de válvulas de seguridad (presión de apertura, estado, fecha de revisión).
  • Reportes de reposición de producto químico.
  • Información de dosificación por punto de tratamiento.
  • Coordenadas GPS del lugar donde se realizó cada tarea (solo mientras la app está en uso).

3.4 Datos de configuración de dispositivos

Parámetros técnicos de calibración de los sensores (coeficientes de tanque, offsets, umbrales de alarma). Se almacenan en el backend IoT y se actualizan automáticamente de forma periódica.

3.5 Alertas y estadísticas operativas

  • Alertas: Registro de alarmas activas y resueltas por dispositivo (niveles críticos, desconexiones, fallos). Se envían por email al equipo operativo.
  • Estadísticas de uso: Métricas diarias de actividad del sistema para análisis operativo interno.

3.6 Datos que el sistema NO recopila

  • Datos de contacto personal no vinculados a la entidad corporativa.
  • Información financiera o de pago.
  • Ubicación en segundo plano (background location).
  • Audio, video o imágenes almacenadas.
  • Datos de comportamiento para publicidad o perfilado.

4. Cómo se usan los datos

  • Autenticación de usuarios y control de acceso basado en roles (RBAC).
  • Monitoreo en tiempo real de dispositivos de campo.
  • Cálculo automático de métricas derivadas (presión, caudal diario, columna de agua).
  • Almacenamiento histórico de telemetría para análisis y auditoría.
  • Gestión y trazabilidad de reportes de mantenimiento.
  • Acceso rápido al último reporte por dispositivo mediante código QR.
  • Envío de alertas automáticas ante eventos críticos.
  • Generación de reportes operativos periódicos.
  • Exportación de datos históricos a solicitud del cliente.

Los datos no se utilizan para publicidad, perfilado conductual ni ninguna finalidad ajena a la operación industrial del sistema.

5. Aislamiento de datos por cliente

La infraestructura cloud y la instancia del backend IoT son dedicadas exclusivamente a Pluspetrol. Los datos de Pluspetrol no se comparten ni mezclan con los de otros clientes de EDGE SA. El acceso está restringido por rol a nivel de token de sesión: cada usuario solo puede ver y operar los datos correspondientes a su perfil.

6. Proveedores de servicios terceros

Losant IoT Platform

Plataforma IoT utilizada como backend middleware. Opera sobre infraestructura cloud en Estados Unidos. Política de privacidad: losant.com/privacy.

Google Cloud Platform (GCP)

Utilizado para almacenamiento histórico, últimos reportes y servicios REST. Google actúa como procesador de datos y cumple con GDPR. Todos los datos están cifrados en reposo (AES-256) y en tránsito (TLS 1.2/1.3). Región: us-central1, Iowa, Estados Unidos. Política: cloud.google.com/privacy.

Myriota (conectividad satelital)

Proveedor de conectividad satelital para dispositivos en zonas sin cobertura 4G. Los mensajes de telemetría se transmiten cifrados y son autenticados mediante JWT al recibirlos en el backend.

No se utilizan SDKs de publicidad, analítica de terceros ni librerías de tracking.

7. Seguridad y cifrado

7.1 Datos en tránsito

  • HTTPS / TLS 1.2–1.3: Todas las comunicaciones entre la app móvil, el dashboard web y el backend.
  • MQTT sobre TLS (puerto 8883): Telemetría de dispositivos 4G hacia el backend.
  • Webhook HTTPS autenticado: Mensajes satelitales hacia el backend.

7.2 Datos en reposo

  • Infraestructura GCP: Cifrado AES-256 nativo gestionado por Google Cloud Key Management.
  • Backend Losant: Cifrado en reposo según infraestructura del proveedor.
  • Dispositivo móvil: Credenciales cifradas a nivel de hardware. Reportes offline en base de datos local cifrada.

7.3 Control de acceso

  • Autenticación por usuario y contraseña. Las contraseñas se almacenan con hash.
  • Tokens de sesión con tiempo de expiración. Re-autenticación requerida al expirar.
  • RBAC embebido en el token: cada rol accede solo a las funciones y datos que le corresponden.
  • Acceso a infraestructura cloud restringido al equipo técnico de EDGE SA.

8. Conectividad y modo sin conexión

Los dispositivos de campo operan con conectividad 4G o satelital. El sistema detecta automáticamente la desconexión y genera alertas al equipo operativo.

La app móvil dispone de modo offline: los reportes se almacenan localmente y se sincronizan automáticamente cuando se restablece la conectividad (store & forward).

10. Exportación y eliminación de datos

El sistema permite exportar la totalidad de los datos históricos en formato estructurado (CSV/JSON) a solicitud del cliente.

Ante la finalización del acuerdo con Pluspetrol:

  • Se entregará el dataset completo en formato exportable antes del borrado definitivo.
  • Las cuentas de usuario serán desactivadas de forma inmediata y eliminadas dentro de los 24 meses siguientes, salvo obligación legal de retención mayor.
  • Los datos en la infraestructura cloud y el backend IoT serán eliminados según el procedimiento acordado.

11. Transferencias internacionales de datos

Los datos son procesados y almacenados en servidores ubicados fuera de Argentina:

  • Google Cloud Platform: Región us-central1, Iowa, Estados Unidos.
  • Losant IoT Platform: Infraestructura en Estados Unidos.

Ambos proveedores cuentan con acuerdos de procesamiento de datos y salvaguardas contractuales equivalentes a las exigidas por la normativa aplicable.

12. Acceso remoto al ambiente de Pluspetrol

EDGE SA no requiere acceso remoto al ambiente interno de Pluspetrol. Toda la comunicación es iniciada por los dispositivos de campo o los usuarios hacia la infraestructura de EDGE SA. No se requiere abrir puertos entrantes en la red de Pluspetrol, solo los siguientes puertos salientes:
  • 443 (HTTPS/TLS): App móvil, dashboard web y comunicaciones con el backend.
  • 8883 (MQTT/TLS): Telemetría de dispositivos 4G de campo.
